# Penwortham After Dark

A free-roaming top-down comedy RPG starring Rick and Laura.

## What is in it

- Multiple connected areas rather than a one-screen demo.
- Drag-your-thumb analogue movement on mobile.
- Character swap: Rick uses rap projectiles, Laura uses guitar-riff shockwaves.
- In-joke quest chain: lost car + glasses, milk, Sauvignon, Prince Andrew 3000, Sunday-roast FATS meltdown.
- Interiors: 4AM Coffee, Old Man Pub, Corner Shop, Sauna Shrine, Wealthy Little Pigs Travel, Tap-ish and Pad Thai Palace.
- Enemies, health, boss fight, dialogue, save state and PWA support.

The original WhatsApp export is **not** stored in this repository. Only selected jokes and references are represented in the game.

## Controls

Mobile:
- Drag the left stick to move.
- **ACT** talks, picks up items and enters doors.
- **ATTACK** uses the active character's move.
- **SWAP** changes between Rick and Laura.

Keyboard:
- WASD / arrow keys to move.
- J to attack.
- K to swap.
- E to interact.
